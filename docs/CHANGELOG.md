# Changelog
## Unreleased
- **Added a Sign out button.** `API.signOut()` existed but nothing called it. The sign-up page header now shows **Sign out** whenever a session exists (profile → final screens); it signs out of Supabase, clears the local avatar draft (so the next account on the same browser starts clean), resets the flow history and returns to the welcome screen. Sign-out from inside `/world` will come later with the phone's **Settings** app (`GAME_DESIGN.md` §5).
- **Documented the exact Google sign-in setup** (Google Cloud OAuth consent screen + Web client ID/redirect URI, pasting the Client ID/Secret into Supabase *Authentication → Providers → Google*, and the Site/Redirect URL allow-list) in `docs/SETUP_VERCEL_SUPABASE.md` §A.7 — needed to clear the `Unsupported provider: provider is not enabled` error when a user taps "Continue with Google". No code change: `onboarding/api.js` already uses Supabase `signInWithOAuth` for the real mode.
- **Fixed the map freezing on "Loading world…".** `vercel.json` had `"trailingSlash": false`, which 308-redirects `/world/` → `/world` (no slash); there the map's relative `vendor/three.min.js` resolves to `/vendor/three.min.js` → 404, so three.js never loaded. Removed that setting and added an explicit `/world` → `/world/` redirect so the map always loads at the slash URL where its relative paths work. Also updated docs to the new Vercel project domain **https://futalife.vercel.app** (the previous `futa-life-ten.vercel.app` project was removed on Vercel).
- **Deployed to GitHub + Vercel.** Initialized the git repo in this folder (added `.gitattributes` for LF line endings), pushed to `github.com/nigeriaprompt-cloud/FUTA-life` replacing the old files (old content preserved on the `backup-old-files` branch). A Vercel project connected to it redeploys `main` automatically — live at **https://futalife.vercel.app** (sign-up page at `/`, map at `/world/`).
- **Switched backend to Vercel + Supabase.** Added `supabase/` (schema, RLS, RPCs, avatar-options seed, SQL tests: 74 checks pass on Postgres 16), `onboarding/api.js` now uses supabase-js (demo mode kept), `live/` (live players, name labels, room chat, waves/DMs, seats, ATM, click-to-walk pathfinding, dev demo with fake backend), `vercel.json`, docs `SUPABASE.md` + `SETUP_VERCEL_SUPABASE.md`. Removed PHP `api/`. Map is now `public/world/index.html` (three.js served locally).
- Added sign-up + character creator prototype (Google/email, username, age gate, 3D studio, story start) — `onboarding/`.
- Added mobile-fast avatar/NPC builder (`avatar/`), options JSON as single source of truth, PHP `AvatarValidator`, onboarding API (`api/`).
- Added docs: SIGNUP_AND_CHARACTER, AVATAR_SPEC, LIFE_LAYER. Roadmap: Phase 0B and 4B added; Phase 8 (contributions) deferred; API/DATA_MODEL/PAYMENTS marked.
