# public/world/game — what is where
- `avatar/` — the 3D people (players + NPCs). Start with `docs/AVATAR_SPEC.md`. Dev page: `avatar/lab.html`.
- `onboarding/` — sign-up + character creator. Open `onboarding/signup.html` (works in demo mode with no server). Settings: `onboarding/config.js`.
Preview locally: from the `public/` folder run `python3 -m http.server 8000` then open http://localhost:8000/world/game/onboarding/signup.html
